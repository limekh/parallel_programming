# Лабораторная работа №5

## 1. Задание

Параллельную версию программы на MPI необходимо также запустить на суперкомпьютере «Сергей Королёв».

## 2. Программа

- `mpi_matrix_mult.cpp` — программа параллельного умножения квадратных матриц с использованием MPI
- `generate_matrices.py` — скрипт для генерации входных матриц
- `run_mpi_1.pbs` — batch-скрипт для запуска программы на 1 процессе
- `run_mpi_2.pbs` — batch-скрипт для запуска программы на 2 процессах
- `run_mpi_4.pbs` — batch-скрипт для запуска программы на 4 процессах
- `run_all_mpi.pbs` — batch-скрипт для автоматического запуска серии экспериментов
- `results.csv` — файл с результатами экспериментов
- `make_plots.py` — скрипт для построения графиков

## 5. Выводы

В ходе лабораторной работы MPI-версия программы умножения матриц была запущена на суперкомпьютере «Сергей Королёв». Были проведены эксперименты для размеров матриц 200, 400, 800, 1200, 1600 и 2000, а также для 1, 2, 4 и 8 процессов.

Полученные результаты показали, что при увеличении числа процессов время выполнения устойчиво уменьшается для всех исследованных размеров матриц. На суперкомпьютере масштабирование оказалось значительно лучше, чем на локальной машине, поскольку вычислительные ресурсы кластера позволяют эффективно использовать большее число MPI-процессов без заметных ограничений по ядрам и памяти.

Наилучшие результаты были получены при использовании 8 процессов. Для большинства размеров матриц ускорение близко к линейному: для 2 процессов оно составляет примерно 2, для 4 процессов — около 4, а для 8 процессов — до 7.7–7.8. Это говорит о высокой эффективности распараллеливания программы на вычислительном кластере.

Таким образом, запуск MPI-программы на суперкомпьютере подтвердил корректность реализации и показал, что использование многопроцессорной архитектуры позволяет существенно сократить время выполнения вычислений.
