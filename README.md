# Лабораторная работа №5

## 1. Задание

Запуск программы перемножения матриц(MPI) на суперкомпьютере «Сергей Королёв».

## 2. Программа

- `mpi_matrix_mult.cpp` — Исходный код программы на C++ с использованием MPI.
- `generate_matrices.py` — Скрипт на языке Python для генерации тестовых матриц заданного размера.
- `run_mpi_1.pbs` — batch-скрипт для запуска программы на 1 процессе
- `run_mpi_2.pbs` — batch-скрипт для запуска программы на 2 процессах
- `run_mpi_4.pbs` — batch-скрипт для запуска программы на 4 процессах
- `run_all_mpi.pbs` — Скрипт системы управления заданиями PBS для отправки задач в очередь суперкомпьютера.
- `results.csv` — файл с результатами экспериментов
- `make_plots.py` — Скрипт для построения графиков зависимостей.

## 3. Запуск программы
```
module purge
module load intel/mpi4
# Сборка
mpicxx -std=c++11 mpi_matrix_mult.cpp -o mpi_matrix_mult
# Подготовка скриптов
sed -i 's/\r$//' run_all_mpi.pbs generate_matrices.py
# Отправка заданий в очередь
sbatch run_all_mpi.pbs
# Просмотр статуса задания
squeue -u $USER
```

## 6. Выводы

В ходе лабораторной работы MPI-версия программы умножения матриц была запущена на суперкомпьютере. Были проведены эксперименты для размеров матриц 200, 400, 800, 1200, 1600 и 2000, а также для 1, 2, 4 и 8 процессов.
Полученные результаты показали, что при увеличении числа процессов время выполнения устойчиво уменьшается для всех исследованных размеров матриц. На суперкомпьютере масштабирование оказалось значительно лучше, чем на локальной машине (лабораторная работа №3), поскольку вычислительные ресурсы кластера позволяют эффективно использовать большее число MPI-процессов без ограничений по количеству физических ядер.
Наилучшие результаты были получены при использовании 8 процессов. Для большинства размеров матриц ускорение близко к линейному: для 2 процессов оно составляет примерно 2.0, для 4 процессов — около 3.9–4.0, а для 8 процессов — до 7.7–7.8. Для матрицы 2000×2000 время выполнения сократилось с 105364 мс до 13654.7 мс, что даёт ускорение 7.72х. Несколько меньшее ускорение для матриц 800×800 (5.47х) и 1200×1200 (6.25х) может быть связано с накладными расходами на коммуникацию между узлами кластера.
Таким образом, запуск MPI-программы на суперкомпьютере подтвердил корректность реализации и показал, что использование многопроцессорной архитектуры позволяет существенно сократить время выполнения вычислений. Сравнение с результатами лабораторной работы №3 (локальный запуск на ноутбуке с 6 процессами) продемонстрировало превосходство кластерной системы: на суперкомпьютере достигнуто ускорение 7.7–7.8х против 3.1–4.6х на локальной машине, что подтверждает эффективность распределённых вычислений для ресурсоёмких задач.
